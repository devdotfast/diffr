# Bundled themes

These are Helix editor themes, vendored unchanged from
https://github.com/helix-editor/helix/tree/master/runtime/themes and licensed under the
Mozilla Public License 2.0 (see LICENSE in this directory).

| name              | file                  |
| ----------------- | --------------------- |
| `default-dark`    | `onedark.toml`        |
| `default-light`   | `onelight.toml`       |
| `gruvbox`         | `gruvbox.toml`        |
| `solarized_light` | `solarized_light.toml` |

Any other Helix theme works through `theme.path` in diffr's config.
